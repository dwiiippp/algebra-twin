# Algebra Twin

Algebra Twin is an AI-powered mathematics learning application designed to help students understand algebra concepts through adaptive learning and misconception analysis.

## Features

### Student

- Learning materials
- Exercise
- Progress tracking
- Misconception analysis
- AI assistant


### Teacher

- Class management
- Student monitoring
- Learning analytics
- Assignment management


## Tech Stack

### Mobile

Flutter

### Backend

FastAPI

### Database

PostgreSQL
